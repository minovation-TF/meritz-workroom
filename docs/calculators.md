# 업무용 계산기 팝업

확인일: 2026-10-25. 대문의 ‘계산기’ 버튼에서 나이·임신주수·날짜·일할계산을 사용한다. 기존 실비계산기는 별도 도구로 유지한다.

- 나이: 양력 생년월일과 기준일로 신규 가입 기준 보험나이, 세는나이, 만나이를 보여준다. 보험나이는 6개월 끝수 기준이며 다음 상령일도 표시한다. 기존 계약은 매년 계약해당일 기준으로 다를 수 있다. 윤일·월말의 해당일이 없으면 그 달 말일 종료 다음 날부터 나이가 바뀌는 달력 기준이다.
- 임신주수: 출생예정일을 40주 0일(280일)로 놓아 기준일까지의 주·일을 역산한다. 의료진이 정한 주수와 예정일이 우선이다. 상품 가입 가능 여부나 보장개시일을 판정하지 않는다.
- 날짜: 두 날짜의 차이, N일 후·전 날짜를 계산한다. 초일 포함 여부를 선택하며 휴일·영업일 자동 조정은 하지 않는다.
- 일할: 전체 금액 × 선택 기간 일수 ÷ 전체 기간 일수. 초일과 원 미만 처리(버림/반올림/올림)를 선택한다. 윤년의 실제 일수를 사용하며 금액은 정수 연산으로 처리한다. 약관의 단기요율·해지환급금을 계산하는 기능은 아니다.

모든 기본 기준일은 한국 시간의 오늘이며 변경할 수 있다. 입력 날짜·금액은 서버로 전송하거나 브라우저 저장소에 저장하지 않는다. 창을 열어둔 동안의 입력값만 유지한다.

## 검증

`node tests/calculators.cjs`: 약관의 나이 예시, 6개월 경계, 윤일·월말, 한국시간, 임신주수의 일수, 날짜 포함 기준, 일할 금액의 정수·반올림 검증.

`node tests/calculators-browser.cjs`: 팝업과 기존 도구, 복사, 입력 오류 시 결과 초기화, 키보드와 초점 복원, 320~1440px 화면 검증. Playwright와 Edge가 필요하다. `CALCULATORS_URL`을 지정하면 공개 배포 주소를 검증한다.
