# 실비계산기 검증 범위

2026-10-16 확인. 사용자가 제공한 정적 HTML을 바탕으로 일반 실손 2~5세대의 건별 기본 공제와 지원하는 입원 연간 자기부담 상한을 계산한다. 가입일만으로 확정하지 않고 전환·재가입 후 현재 약관을 선택하도록 안내한다.

## 수정한 사항

- 5세대 급여 통원: 병원 종류별 고정 비율과 중증 체크에 따른 임의 20% 적용을 제거했다. 영수증의 본인부담금과 공단부담금으로 실제 본인부담률을 구한다. 공단부담금 미입력과 명시적 0원을 구별한다.
- 5세대 비급여: 중증·비중증 특약 선택을 반영한다. 병·의원 비중증 입원의 회당 300만원 한도를 적용한다.
- 확인되지 않은 5세대 상급병실료·별도 3종 특약 계산은 제외한다. 중증의 도수·주사 등까지 일괄 미보장으로 설명하던 문구를 제거했다.
- 음수, 지수 표기, 문자가 섞인 입력을 양수로 오인하지 않는다. 숫자·쉼표·원·만/천/억 단위 입력을 지원하며 안전 범위 밖 입력은 결과 확정을 막는다.
- 2·3세대 기본 입원의 급여·비급여 자기부담 합계에 연간 200만원 상한을 적용한다. 5세대는 중증 특약 가입·산정특례 대상 치료·종합/상급종합병원 입원 조건을 모두 충족한 중증 비급여 자기부담금에 연간 500만원 상한을 적용한다. 앞선 입원의 같은 보험연도·보장종목 누적 자기부담금을 입력할 수 있으며 미입력은 0원으로 명시한다. 통원·상급병실 차액·별도 3종 특약은 제외한다.
- 5세대 급여 입원에 200만원 상한이 있다고 가정하던 안내/계산 대기를 제거했다. 확인한 2605.1 일반형 약관의 급여 입원은 20% 자기부담이다. 4세대 급여 입원 상한은 이번 계산 대상에서 제외하며 큰 금액의 확인 요청을 유지한다.
- 외부 폰트 요청을 제거하고 WORKROOM의 로컬 글꼴과 홈 이동을 적용했다. 입력 의료비는 서버로 보내지 않는다.

## 계산 대상과 한계

2·3세대는 선택한 일반형의 정액/정률 공제와 외래·약국별 사용자가 정한 회당 한도, 3·4세대는 가입한 3종 특약의 1회 금액을 가정한다. 해당 세대의 모든 개별 약관을 검증했다는 의미는 아니다.

연간 보상한도·기지급 보험금·4세대 급여 입원 자기부담 상한·치료 횟수·비례보상·면책/감액·보상 제외 여부는 계산하지 않는다. 2·3세대 기본 입원 200만원과 5세대 조건을 충족한 중증 비급여 입원 500만원 자기부담 상한은 계산한다. 누적액은 달력연도가 아닌 계약일·매년 계약해당일 기준의 같은 보장종목 금액이다. 상해·질병을 임의로 합산하지 않으며 이번 영수증 금액에는 앞선 입원을 다시 더하지 않는다. 1세대, 노후·유병력자·단체 실손은 지원하지 않는다. 5세대의 별도 3종 비급여와 상급병실료는 지원하지 않는다. 5세대 동일일·동일질환의 외래와 약국은 한 줄로 합산한다. 결과는 보장 대상 금액을 입력한 경우의 기본 공제 추산이다.

## 계산 상세 내역 (2026-10-16)

- 결과의 `계산 내역 보기`에서 입력액, 정률/정액 공제 후보, 선택 이유, 실제 자기부담, 한도 초과 차감, 예상 보험금을 표시한다. 첫 금액 입력 시 펼쳐지고 입력 중 접힘 상태를 유지한다.
- 2·3세대 통원의 합산 공제, 2세대 정액 전용 유형, 외래/약국 별도 한도, 3·4세대 비급여 3종, 4·5세대 통원 분리 공제, 입원과 상급병실료를 각각 계산 결과에 연결한다.
- 5세대 급여는 실제 건보 본인부담률 계산과 세 가지 공제 후보를 보여준다. 공단부담금 누락은 계산 대기로, 특약 미선택은 제외 금액으로 구별하며 자기부담 공제로 표시하지 않는다.
- 공제 기준액이 입력액을 넘어도 실제 차감액은 입력액을 넘지 않는다. 한도 차감과 원 미만 버림을 별도로 기록하여 입력액과 보험금의 차이를 대조한다. 입원은 구성 항목을 합산한 뒤 원 미만을 버린다.
- 모바일 하단의 `계산 내역` 버튼으로 결과 위치로 이동한다. 상세 내역을 펼치면 데스크톱 결과의 고정을 풀어 긴 내용을 스크롤할 수 있다.
- 기본 공제와 병실료 산식에 입원 연간 자기부담 상한을 연결한다. 상급병실료 차액을 입력하고 일수를 빠뜨린 경우에는 누락을 보완할 때까지 전체 결과를 `입력 확인 필요`로 표시한다.

`node tests/silson-breakdown.cjs`: 공제·한도·제외·계산 대기·원 미만 버림의 금액 대조, 5,000개 금액 조합, 실제 페이지 스크립트/입력 이벤트 연결을 검증한다. DOM 대체 환경 검사이며 브라우저 레이아웃 검증을 대신하지 않는다.

## 기존 계산 검증

`node tests/silson-calculator.cjs`: 금융위 급여 예시(본인부담 20만/공단 30만 → 12만원), 2~5세대 예시, 공제 미만/회당 한도, 특약 선택, 입력 파싱, 1,000개 금액 조합의 비음수·지급액 상한 검사.

`node tests/silson-browser.cjs`: 실제 입력·선택·행 추가/삭제·비교·홈 왕복, 320~1440px 표시, 외부 요청 여부. Playwright 브라우저가 필요하며 공개 사이트는 `SILSON_TEST_URL`로 지정한다.

브라우저 자동 검증을 처음 실행할 때는 프로젝트 폴더에서 `npm install -D playwright`와 `npx playwright install chromium`을 한 번 실행한다. 설치된 브라우저 대신 Edge·Chrome 또는 별도 실행 파일을 사용하려면 `SILSON_BROWSER_CHANNEL=msedge` 또는 `SILSON_BROWSER_CHANNEL=chrome`, `SILSON_EXECUTABLE_PATH=/path/to/browser`를 지정한다. 예시는 `SILSON_TEST_URL=https://minovation-tf.github.io/meritz-workroom/silson-calculator.html node tests/silson-browser.cjs`다.


## 연간 상한 검증 (2026-10-16)

`node tests/silson-annual.cjs`: 2세대 3유형·3세대 2유형의 상한 전후와 누적액 0/180만/200만/초과, 급여·비급여 합산 상한, 상급병실료·통원·별도 3종 제외, 5세대 특약/산정특례/병원 조건별 적용, 500만원 전후·누적 소진, 금액 정산, 실제 입력 이벤트·세대 간 상태 보존·예시 및 초기화를 확인한다.

- 예: 2세대 표준형 급여 150만원 + 비급여 100만원, 앞선 자기부담 180만원 → 기본 공제 50만원 중 남은 20만원만 공제 → 이번 예상 보험금 230만원.
- 예: 5세대 조건 충족 중증 비급여 입원 2,000만원 → 기본 자기부담 600만원 대신 500만원 공제 → 1,500만원. 앞선 대상 자기부담 400만원이면 남은 100만원만 공제 → 이번 보험금 1,900만원.
- 산정특례 확인 전에는 중증 비급여 계산을 대기한다. 종합/상급종합병원 외 입원은 30% 공제를 유지한다. 특약 미가입은 제외 금액으로 표시한다.
- 2·3세대 가입 유형 카드는 모두 `급여 ○% · 비급여 ○% 자기부담`으로 통일하며, 2세대 90% 보상형의 통원 정액 공제 예외를 함께 안내한다.
