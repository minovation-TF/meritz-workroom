# 실비계산기 검증 범위

2026-10-16 확인. 사용자가 제공한 정적 HTML을 바탕으로 일반 실손 2~5세대의 건별 기본 공제를 계산한다. 가입일만으로 확정하지 않고 전환·재가입 후 현재 약관을 선택하도록 안내한다.

## 수정한 사항

- 5세대 급여 통원: 병원 종류별 고정 비율과 중증 체크에 따른 임의 20% 적용을 제거했다. 영수증의 본인부담금과 공단부담금으로 실제 본인부담률을 구한다. 공단부담금 미입력과 명시적 0원을 구별한다.
- 5세대 비급여: 중증·비중증 특약 선택을 반영한다. 병·의원 비중증 입원의 회당 300만원 한도를 적용한다.
- 확인되지 않은 5세대 상급병실료·별도 3종 특약 계산은 제외한다. 중증의 도수·주사 등까지 일괄 미보장으로 설명하던 문구를 제거했다.
- 음수, 지수 표기, 문자가 섞인 입력을 양수로 오인하지 않는다. 숫자·쉼표·원·만/천/억 단위 입력을 지원하며 안전 범위 밖 입력은 결과 확정을 막는다.
- 연간 자기부담 상한에 걸리는 큰 입원 금액은 확정 합계를 표시하지 않고 누적 내역 확인을 요청한다. 일반 결과에도 미반영 범위를 표시한다.
- 외부 폰트 요청을 제거하고 WORKROOM의 로컬 글꼴과 홈 이동을 적용했다. 입력 의료비는 서버로 보내지 않는다.

## 계산 대상과 한계

2·3세대는 선택한 일반형의 정액/정률 공제와 외래·약국별 사용자가 정한 회당 한도, 3·4세대는 가입한 3종 특약의 1회 금액을 가정한다. 해당 세대의 모든 개별 약관을 검증했다는 의미는 아니다.

연간 보상한도·기지급 보험금·입원 자기부담 누적 상한·치료 횟수·비례보상·면책/감액·보상 제외 여부는 계산하지 않는다. 1세대, 노후·유병력자·단체 실손은 지원하지 않는다. 5세대의 별도 3종 비급여와 상급병실료는 지원하지 않는다. 5세대 동일일·동일질환의 외래와 약국은 한 줄로 합산한다. 결과는 보장 대상 금액을 입력한 경우의 기본 공제 추산이다.

## 계산 상세 내역 (2026-10-16)

- 결과의 `계산 내역 보기`에서 입력액, 정률/정액 공제 후보, 선택 이유, 실제 자기부담, 한도 초과 차감, 예상 보험금을 표시한다. 첫 금액 입력 시 펼쳐지고 입력 중 접힘 상태를 유지한다.
- 2·3세대 통원의 합산 공제, 2세대 정액 전용 유형, 외래/약국 별도 한도, 3·4세대 비급여 3종, 4·5세대 통원 분리 공제, 입원과 상급병실료를 각각 계산 결과에 연결한다.
- 5세대 급여는 실제 건보 본인부담률 계산과 세 가지 공제 후보를 보여준다. 공단부담금 누락은 계산 대기로, 특약 미선택은 제외 금액으로 구별하며 자기부담 공제로 표시하지 않는다.
- 공제 기준액이 입력액을 넘어도 실제 차감액은 입력액을 넘지 않는다. 한도 차감과 원 미만 버림을 별도로 기록하여 입력액과 보험금의 차이를 대조한다. 입원은 구성 항목을 합산한 뒤 원 미만을 버린다.
- 모바일 하단의 `계산 내역` 버튼으로 결과 위치로 이동한다. 상세 내역을 펼치면 데스크톱 결과의 고정을 풀어 긴 내용을 스크롤할 수 있다.
- 보험금 산식은 유지한다. 상급병실료 차액을 입력하고 일수를 빠뜨린 경우에는 누락을 보완할 때까지 전체 결과를 `입력 확인 필요`로 표시한다.

`node tests/silson-breakdown.cjs`: 공제·한도·제외·계산 대기·원 미만 버림의 금액 대조, 5,000개 금액 조합, 실제 페이지 스크립트/입력 이벤트 연결을 검증한다. DOM 대체 환경 검사이며 브라우저 레이아웃 검증을 대신하지 않는다.

## 기존 계산 검증

`node tests/silson-calculator.cjs`: 금융위 급여 예시(본인부담 20만/공단 30만 → 12만원), 2~5세대 예시, 공제 미만/회당 한도, 특약 선택, 입력 파싱, 1,000개 금액 조합의 비음수·지급액 상한 검사.

`node tests/silson-browser.cjs`: 실제 입력·선택·행 추가/삭제·비교·홈 왕복, 320~1440px 표시, 외부 요청 여부. Playwright와 Edge가 필요하며 공개 사이트는 `SILSON_TEST_URL`로 지정한다.
